# GPU Checker v3 验证记录 · 2026-11-03

以下为实际执行的验证，服务器工作负载未被暂停、终止或更改。

- 40 项自动测试通过：新增 Windows 凭据真实写入／读取／删除、按连接地址绑定密码、保存密码自动连接、暂停状态跨窗口恢复、无 GPU 与驱动不可用区分、SSH 关闭竞态，以及活动会话下关闭窗口后事件循环退出检查；保留原有采集、认证、多主机和 config 校验检查。
- 使用真正的本地 SSH 服务验证内置密码认证、两次连续数据流、未知主机接受/拒绝、已记录主机密钥变化拒绝、错误密码拒绝。采样数据为明确的测试数据，不作为 GPU 测量结果。
- 对用户授权的 null-sf.top：系统 OpenSSH 和内置密钥分别连续采样 3 次，均读到 5 张 GPU、4 个用卡进程及 cwd。数值会随真实工作负载变化。
- 新增用户授权的 server-183（系统 SSH config 别名）只读验证：成功读取 2 张 RTX 4090 及用卡进程。
- 两台真实主机并行测试：null-sf.top 为 5 张 GPU，server-183 为 2 张 GPU；在两台之间切换 22 次。模拟关闭 null-sf.top 的本机 SSH 客户端后，183 继续采样，null-sf 自动重连恢复。结束时分别收到 4 次、5 次有效采样。
- 另外验证过同一真实主机的 OpenSSH 和内置密钥双会话并行；并非把该测试当作两台物理主机。
- 只关闭本机测试 SSH 客户端来模拟断网；未向远端 GPU 工作进程发送信号。
- 新版界面及配置编辑弹窗已经截图检查。preview.png 为两台真实主机同时在线、右侧选中 null-sf.top 的界面；config-editor.png 为缺少 User 时阻止保存的界面。图标保留并嵌入 exe。
- v3 新增用户提供的无 GPU 主机，只用授权账号做只读验证。程序从 Windows 凭据管理器自动读取已记住密码，三台主机并行得到 5、5、4 次采样，GPU 数量分别为 5、2、0。无 GPU 主机暂停状态成功保存，停止监控和关闭窗口均能完成。
