# Android 验证

当前发布：1.0.14，Windows 配套版本 14.1.5。

- 浏览器 20 项通过，覆盖八种竖屏尺寸、固定顶部、进程自适应折叠与滑动过渡、日夜渐变、菱形对齐、历史时间游标与边缘渐隐。
- 爆炸测试验证最后点击位置、页面顶层画布、闪光淡入淡出；光条验证连续 SVG 周界运动、爆炸时同步消失、延迟复出及恢复后淡入，布局保持稳定。
- Vitest 核心逻辑测试覆盖 config 解析、可用性判断、历史缺测容忍。
- Android 11 模拟器 / WebView 83 验证原生 SSH 密码认证、保存凭据、私钥库、指纹变化拒绝、冻结快照、重启恢复、历史缓存清理和三种尺寸/DPI；SSH 传输使用隔离合成测试服务器，GPU 数值为合成样本，不冒充物理 GPU 验证。
- 当前版本在同一模拟器检查 SVG 光条实际移动、安装与启动；图标渲染测试覆盖三种密度与三种尺寸。Windows 水波修复相关 9 项测试及隔离存储启动检查通过。

尚未实测：MIUI 和其他厂商真机、Android 8/15/16 真机、所有 SSH 算法和私钥格式、两小时空闲的长期实机计时。Android 最低系统声明不代表上述设备均已覆盖。

APK 使用测试证书签名。发行包不含个人主机、密码、私钥或本机 SDK 路径。系统可能限制后台监控；再次进入应用会恢复已启用的连接。测试脚本默认使用隔离模拟器 emulator-5580，不操作真实手机。

运行方式见 [README](README.md)。
