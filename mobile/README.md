# GPU Checker Android

独立 Android 应用：React + TypeScript + Vite + Capacitor 8，Kotlin/JSch 在手机上直接建立 SSH 连接。无需电脑、Web 服务或额外后端；远端需要 Linux、Python 3，以及用于 GPU 采集的 NVIDIA 驱动。无 GPU 主机也可保持 SSH 连接。

Windows 与 Android 分别构建，移动端代码与构建都在本目录，共享只读采集探针。

应用固定竖屏使用，界面按不同竖屏尺寸与 DPI 适配，不提供横屏布局。Android 16 大屏声明方向兼容选项；若系统仍强制横向窗口，界面显示「请竖屏使用」，不展开横屏操作界面。浏览器预览请使用竖向窗口或手机设备模式。

## 安装与连接

安装 `delivery/GPUChecker-Android-v1.0.14-release-test.apk`，支持 Android 8.0+，建议使用更新的 Android System WebView。当前 APK 为本地测试签名，不是应用商店发行签名。

1. 点「+」添加主机，填写地址、用户名、端口，选择密码或私钥。也可粘贴/导入 SSH config，或导入本应用导出的 JSON 主机配置。
2. 点「安全配置认证」。**密码在 Android 原生密码框中输入**，勾选「记住认证」后保存。私钥模式可选择已保存的私钥，也可在原生窗口导入 PEM/OpenSSH 私钥，再输入私钥口令（未加密可留空）。
3. 首次连接会显示服务器 SHA256 指纹，向管理员核对后再信任。指纹变化会拒绝连接；编辑主机中的重置指纹功能需要再次确认。
4. 凭据由 Android Keystore AES-GCM 加密保存在本机，不回传 React，不进入配置导出、日志或 APK。下次进入应用会自动连接已启用且已保存凭据的主机。未勾选记住时仅在当前进程内保留认证。

手机需要能够访问服务器网络；内网地址通常需要同一 Wi-Fi 或手机 VPN。桌面 SSH Agent、电脑上的私钥路径不会自动迁移。修改地址、端口、用户或认证方式后，需要重新配置凭据。导出/迁移只包含主机元信息，手机凭据不可跨设备复制。

## 电脑私钥导入与多主机共用

这是正常的 SSH 密钥管理方式：同一把密钥只导入一次，多台已授权服务器都可以选择使用。手机与电脑也可以使用各自独立的密钥，便于单独撤销手机权限。

1. 用 USB 文件传输等可信方式，将电脑的**私钥文件**复制到手机（例如「下载」目录）。选择私钥本身，不能只复制 `.pub` 公钥；应用不会自动读取电脑文件。
2. 打开右上角「设置」→「SSH 私钥库」→「导入」，在 Android 系统文件选择器中选中文件。
3. 在原生安全窗口中设置名称、输入私钥口令，点保存。未加密的私钥可留空口令。导入时会验证私钥及口令，错误时留在窗口内重试，不会添加不可用条目。
4. 添加或编辑主机，选择「私钥登录」，在「使用的私钥」中选择已导入的名称，保存。其他主机选择同一条即可，不必再次导入或填写口令。
5. 下次启动应用，已启用的主机直接使用本机加密保存的密钥和口令连接。

密钥库支持改名、按公钥 SHA256 指纹去重、显示引用主机数量。密钥及口令经 Android Keystore 加密保存，界面仅得到名称、算法、公开指纹等元信息，不提供私钥导出。导入完成后可手动删除手机「下载」目录中的原始副本，保留电脑原文件；应用不会擅自删除所选文件。

删除密钥前会提示受影响主机，并暂停这些主机，保留其主机条目和最后快照，供以后重新选密钥。删除主机不会删除共享密钥。升级时会尝试将旧版逐主机保存的有效私钥迁移到密钥库；迁移失败时保留原凭据。主机配置导出不携带本机密钥 ID 或任何凭据，换手机后需要重新导入并选择。

## 功能

GPU 条目在原分区中放不下时，进程区自动折叠成带球面扫光的栏，点击恢复原限高；同一次打开期间按主机保留手动展开/折叠选择，不会被采样刷新反复改变。启动器与顶栏使用已选定的 B2 四叶机甲核心图标。

- 固定顶部控制栏与横向主机列表；下方横向 GPU 条目、进程列表分别纵向滚动；进程列表无搜索框，单行显示 PID、GPU、显存与用户，点击查看完整详情；深浅主题与机械中文字体。
- 多主机独立连接、暂停/恢复、重试、重启后保留主机/暂停状态/冻结快照；保留原生 GPU 编号。
- 实时 GPU 负载、显存、温度、功耗、用户/PID/目录/可执行文件等只读进程元信息。原样复用 Windows 的 `src/remote_probe.py`，不会写入远端文件、改变 GPU 设置、读取进程环境变量或发送进程信号。
- 空闲、可用、轻量占用、占用、不可用状态；可用判定至少连续 10 秒/3 次采样，权限或数据不完整时保守处理。颜色只是当前资源提示，不代表资源预约或保证可共卡。
- 按曲柄连杆几何联动的四缸运动、状态色细水波叠加、从实际点击点发生的连点加速/粉末爆炸/干扰重现，冻结裂纹和金色火花，主题渐变。连续核心利用率 0% 达到 2 小时后亮起边框光点，允许最长 60 秒缺测。
- 按主机/单卡查看历史：仅显存占用 GiB、显存读写利用率 % 两条曲线，支持单指平移、双指缩放、时间游标和时间范围选择。显存读写利用率不是显存容量占比；驱动不支持时显示缺测。
- SQLite 本地历史缓存默认 256 MB，可设置 32–1000 MB，预留日志空间并自动淘汰最老数据；设置内可查看大小和清除历史。快照与主机配置不会随历史清理删除。

当前直连版本不支持跳板机/ProxyJump、ProxyCommand、Include、Match、硬件安全密钥、SSH Agent、交互式 MFA；导入遇到这些指令会明确报错。服务器 `/proc` 权限受限时不会尝试提权。

监控使用带通知的前台服务。Android 省电策略、厂商后台限制仍可能中止连接，Android 15+ 的 dataSync 后台时间额度也适用；返回应用后可恢复。应用退出期间不会伪造历史样本，不承诺手机后台全天持续采样。

## 浏览器开发

需要 Node.js 22.12+、npm 11+。在本目录运行：

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址（通常 `http://127.0.0.1:5173`），修改代码立即热更新。浏览器顶部明确显示演示模式，所有 GPU 数据为模拟数据；浏览器不接收密码，也不执行 SSH。APK 会内嵌静态资源，不依赖 Vite。

## Android 构建

通过 Android Studio 安装 SDK Platform 36、Build Tools 36.0.0，准备 JDK 21+，设置 `JAVA_HOME` 和 `ANDROID_HOME`，然后：

```powershell
.\build.ps1                 # 生成可安装、非 debuggable 的测试签名 release APK
.\build.ps1 -DebugBuild     # 模拟器/WebView 调试版本
```

脚本只生成本机 `android/local.properties`，不在源码里固化 SDK、JDK 或用户目录绝对路径。不要直接修改生成的 Kotlin 文件：原生源文件位于 `native/`，`scripts/prepare-native.mjs` 负责同步及复制共享探针。Gradle wrapper 首次下载需要网络；可通过本机 Gradle 用户配置设置代理。

正式发行需要用自己的长期签名证书替换 `prepare-native.mjs` 中的 debug 测试签名配置，妥善备份私钥。仓库不包含签名私钥。

## 测试

```powershell
npm test
npm run test:browser        # 先启动 npm run dev；默认使用本机 Edge
```

原生测试：先 build/sync/prepare，再在 `android/` 执行 `gradlew :app:assembleDebugAndroidTest`，安装 app 和 androidTest APK 后运行 AndroidJUnitRunner。测试源码位于 `native-test/`。

`scripts/ssh_fixture.py`、`scripts/android-functional.mjs`、`scripts/android-key-functional.mjs` 用于隔离模拟器的真实 SSH 传输测试；测试 GPU 数值是合成样本，不冒充物理 GPU 测试。脚本默认显式使用 `emulator-5580`，不触碰真实手机或生产服务器；需要本机 Python Paramiko 和 Playwright Android driver。详细验收见 [TESTING.md](TESTING.md)。
