# GPU Checker

Windows 多主机 NVIDIA GPU 监控工具。通过 SSH 实时查看显卡、用卡进程、用户和工作目录，支持日夜主题与机甲风界面。

## 下载与使用

到 [Releases](https://github.com/TheBlueBanisters/GPU-Checker/releases/latest) 下载 Windows x64 ZIP，解压后运行 `GPUChecker.exe`，无需安装 Python。

1. 添加主机，或导入／粘贴 SSH config。
2. 需要输入服务器密码的主机，按下方“密码登录与记住密码”设置；已配置免密的主机可使用 OpenSSH 或私钥。
3. 左侧主机并行监控，点击切换视图；暂停状态会记住。

## 密码登录与记住密码（常用）

**没有配置 SSH 免密、平时需要手动输入服务器密码，也可以保存一次后自动连接。**

1. 点击“添加主机”；如果已导入 SSH config，选中左侧对应主机，再点击“编辑”。
2. 填写或核对“主机”“用户名”“端口”。主机可填域名、IP 或已导入的 SSH 别名；端口按服务器设置填写，通常为 `22`。
3. 将“认证方式”改为 **“密码登录（内置）”**，在“密码 / 私钥口令”中输入**服务器登录密码**，无需填写私钥文件。仅导入 SSH config 不会保存密码，也不会自动切换成密码登录。
4. 勾选 **“记住密码（Windows 凭据管理器，用于自动连接）”** 和 **“启动程序时自动监控此主机”**；需要断线重连时，再保留“连接中断后自动重连”。
5. 点击 **“保存并监控”**。首次连接按提示核对并确认服务器指纹；认证成功后即可监控，无 GPU 主机也会保持 SSH 连接。

之后正常关闭并重新打开程序，会自动读取已保存密码并尝试连接。再次编辑时，密码框提示“已记住密码；留空可继续使用”，不必重复输入。**主动暂停的主机重启后仍保持暂停**，点击“恢复监控”即可使用已保存密码连接。

- **改密码**：编辑主机，输入新密码，保持“记住密码”勾选，再保存。修改主机地址、SSH 别名、用户名或端口后，也需重新输入并保存。
- **只用一次／忘记密码**：取消“记住密码”并保存；已有保存记录也会删除，当前连接仍可使用本次输入或原有密码，下次重新打开程序需再次输入。
- **保存位置**：当前 Windows 用户的凭据管理器，不写入 JSON、SSH config 或迁移包。换电脑或换 Windows 用户后，需重新输入；复制 EXE 不会带走密码。

内置密码模式仅支持直连；含 `ProxyJump`／`ProxyCommand` 的跳板连接需使用 OpenSSH 模式，不能套用上述保存密码流程。

## 主要功能

- GPU 显示负载、显存、温度、功耗和趋势；进程可查看用户与目录。
- 彩色菱形区分空闲、可用、轻量占用、占用和不可用状态；可用性是资源提示，不预留资源。
- 离线保留最后快照；暂停时保留上次 GPU 状态标记，历史数据不计入当前可用数量。
- 无 GPU 主机也能保持 SSH 连接。采集只读，不控制服务器进程。
- 支持窗口与系统缩放适配、日夜渐变切换；连续点击 GPU 卡片可触发粉尘爆炸彩蛋，附带轻盈短音效，仅影响本地界面。

客户端面向 Windows 10/11 x64（已验证 Windows 11）；远端需要 Linux、Python 3.6+，GPU 监控另需 NVIDIA 驱动与 `nvidia-smi`。

配置、迁移、连接限制及构建方法见 [使用说明](docs/USAGE.md)。默认配置位于 `%USERPROFILE%\.gpu-checker`，更新程序会保留原有主机和快照。发行包不包含个人配置或凭据。
